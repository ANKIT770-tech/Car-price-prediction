# Car-price-prediction
Developed a car price prediction model using Random Forest Regressor and a robust machine learning pipeline. The project involved analyzing historical car sales data and applying preprocessing, feature engineering, and model evaluation techniques to accurately predict the selling price of used cars.

Key Highlights:
Feature Engineering: Calculated Car_Age from Year and removed redundant features.
Preprocessing: Used StandardScaler for numerical features and OneHotEncoder for categorical data through ColumnTransformer.
Modeling: Implemented RandomForestRegressor within a Pipeline for clean, end-to-end training and prediction.
Evaluation Metrics: Achieved performance measured using MAE, RMSE, and R² score.
Visualization: Plotted actual vs predicted prices for easy performance inspection.
This model can assist used car platforms or dealers in estimating competitive prices for listings based on historical attributes.
